# Explicit Learning Packets

A learning packet is one small, user-reviewed learning note. Agents, browsers,
CMD and PowerShell can prepare this same JSON format. A person chooses the
packet at `https://juri-halveth.github.io/lernstudio/#bridge`, sees its preview
and uses the continue button to follow the lesson. On a local copy the same
route is `#bridge`. The preview stays in the opened tab. The browser integration
owns explicit file selection, preview and the continue button; this module
supplies validation and links.

The site is static GitHub Pages. These public read endpoints are generated by
the main build:

- `https://juri-halveth.github.io/lernstudio/api/manifest.json`
- `https://juri-halveth.github.io/lernstudio/api/lessons.json`
- `https://juri-halveth.github.io/lernstudio/api/learning-contract.v1.json`
- `https://juri-halveth.github.io/lernstudio/api/example-learning-packet.json`

Fetching a published catalogue is a separate explicit read by its consumer.
The packet module and CLI never fetch these endpoints or a packet's source.
Pages supplies no unauthenticated write API. Public curriculum changes use
reviewed pull requests. Local import is not publication, a completed lesson,
an account update or evidence of learning. Public availability of the new
files depends on the main build's public-file list and a later deployment.

The manifest and catalogue bind the curriculum with SHA-256 after the explicitly
declared `UTF8_LF_NORMALIZED` transformation. This makes their generated content
stable across Windows and Linux checkouts. It binds the normalized source text,
not authorship or learning success. The separate Pages `build-info.json` binds
the actual shipped bytes.

## Contract

`api/learning-contract.v1.json` is the closed JSON Schema 2020-12 description.
`learning-packets.js` is the runtime validator. The lesson-ID schema pattern
uses Unicode-aware ECMAScript regular expressions (`u` flag). Every field is
required:

| Field | Accepted value |
| --- | --- |
| `schema` | Exactly `lernstudio.learning-packet.v1` |
| `id` | 1-96 ASCII letters, digits, `_` or `-`; first character alphanumeric |
| `title` | 1-120 Unicode characters, not whitespace only |
| `lessonId` | A catalogue lesson ID or `null`; 1-96 Unicode letters/numbers, combining marks, `_` or ASCII `-`, starting with a letter/number |
| `observation` | 1-2000 Unicode characters, not whitespace only |
| `question` | 1-500 Unicode characters, not whitespace only |
| `source` | Exactly `{ "kind": ..., "ref": ... }` |
| `source.kind` | `USER_NOTE`, `LOCAL_EXERCISE` or `PUBLIC_SOURCE` |
| `source.ref` | `null`, an absolute HTTPS URL without credentials, or a URN; at most 2048 characters |
| `recordedAt` | Real ISO calendar timestamp with `T`, seconds and `Z` or `+/-HH:mm`; optional 1-3 fractional digits |
| `publication` | Exactly `LOCAL_DRAFT_ONLY` |

The whole UTF-8 input, including whitespace, is capped at 128 KiB (131072
bytes). Character limits count Unicode scalar values. The CLI rejects invalid
UTF-8 bytes; browser consumers must also decode bytes with a fatal UTF-8 decoder.
The module receives already decoded text and rejects unpaired surrogates, year
zero, leap seconds, timezone-less dates and calendar rollover. Text may contain
tab, CR and LF, but no other C0/C1 control
characters. Text is preserved exactly: markup is text, not HTML or Markdown to
execute. A source reference is an attribution string, not an instruction.
HTTPS references reject whitespace, backslashes and malformed percent escapes.
URNs use a 2-32 character ASCII namespace and nonempty ASCII namespace-specific
text with valid percent escapes. Source spelling is preserved.

There are no secrets, files, raw-log, credential or command fields. Unknown
fields are rejected at both levels. Do not put those items in the free-text
fields either. Schema validation checks structure and bounds; the person
reviewing the packet checks its content, privacy and accuracy. A timestamp and
source reference are supplied claims, not authenticated provenance.

## JavaScript API

Load `learning-packets.js` as a normal script for `globalThis.LernPackets`, use
AMD, or `require('./learning-packets.js')` from CommonJS. It has no dependencies.

```js
LernPackets.parse(text, knownIds);             // fresh validated plain object
LernPackets.stringify(packet, knownIds);       // pretty JSON plus final newline
LernPackets.link(packet, baseURL, knownIds);   // URL string only
```

All three functions throw `Error` with a field-oriented message on invalid
input. `knownIds` is an optional array of up to 100000 syntactically valid IDs.
Provide the current catalogue's lesson IDs when accepting a browser import.
If provided, any non-null `lessonId` must be in that array; an empty array
permits only `lessonId: null`. Omitting it checks syntax, not lesson existence.
The module has no curriculum import or implicit catalogue lookup.
Lesson IDs and `knownIds` entries retain their exact Unicode spelling. Composed
and decomposed forms are distinct unless both occur explicitly in the supplied
catalogue; no normalization or case folding occurs. Packet `id` remains ASCII.

`baseURL` defaults to `https://juri-halveth.github.io/lernstudio/`. A caller may
explicitly provide another HTTPS directory URL ending in `/`, without credentials,
query or fragment, for its own copy. A lesson produces `#lesson/<lessonId>`;
`lessonId: null` produces the mission home `#home`. No note text, packet ID,
timestamp or source is embedded in the link. Opening that link does not import
a note. The import route remains exactly `#bridge`.

Exports also include frozen `SCHEMA`, `BASE_URL`, `MAX_BYTES` and `LIMITS`.
The API does not modify its input, access storage, navigate, read files, fetch,
run processes or schedule work. Object APIs accept plain data properties;
executable object properties are rejected. The interchange boundary is JSON
text. Callers must not pass executable objects or proxies as packet data.
Render every field with `textContent` or form `.value`, never `innerHTML`.

At the explicit file-import boundary, check the file size before reading and
use strict decoding so invalid bytes are not silently replaced by `File.text()`:

```js
if (file.size > LernPackets.MAX_BYTES) throw new Error("Maximum packet size: 128 KiB.");
const bytes = await file.arrayBuffer();
const text = new TextDecoder("utf-8", { fatal: true, ignoreBOM: true }).decode(bytes);
const packet = LernPackets.parse(text, knownIds);
```

## CMD / Node.js

Node.js 18 or later is required. Run from the repository directory:

```bat
node werkzeug/learning-packet.mjs validate api/example-learning-packet.json
node werkzeug/learning-packet.mjs link api/example-learning-packet.json
node werkzeug/learning-packet.mjs create --id note-fractions-01 --title "Brueche verstehen" --lesson-id null --observation "Ein Viertel ist die Haelfte von einem Halben." --question "Wie viele Viertel ergeben ein Ganzes?" --source-kind USER_NOTE --source-ref null --recorded-at 2026-10-02T10:00:00Z
```

`validate` prints the validated packet, `create` prints the explicitly supplied
note and `link` prints only its navigation URL. Success exits 0; a rejected
input exits 1, prints a concise error to stderr and no packet to stdout. Unknown,
repeated or missing flags fail. All eight create flags are required; the CLI
does not invent an ID or observation time. Exact literal `null` is accepted for
`--lesson-id` and `--source-ref`. `--help` shows usage.

All commands accept `--known-ids IDS.json`, an explicitly chosen local UTF-8
JSON array such as `["einstieg-0-1"]`, limited to 128 KiB. A caller extracts IDs
from its reviewed catalogue; this is not the raw `lessons.json` response.
`link` also accepts `--base-url HTTPS_DIRECTORY`. Paths must be regular local
files; URLs, UNC/device paths, alternate streams, symlinks and directories fail.
Input files are never overwritten. The CLI does not read environment variables,
tokens, credentials, clipboard content or extra files. To retain output, use an
explicit UTF-8 redirection to a new local file and review it before import.

## PowerShell

The wrapper requires PowerShell 7.3+ so native argument-array passing preserves
quotes and text exactly. Use `pwsh`, including when launching it from CMD:

```powershell
pwsh -NoProfile -File werkzeug/learning-packet.ps1 validate api/example-learning-packet.json
pwsh -NoProfile -File werkzeug/learning-packet.ps1 link api/example-learning-packet.json
```

Inside PowerShell 7.3+, literal note text can be passed in an explicit array:

```powershell
$packetArguments = @('create', '--id', 'note-fractions-01', '--title', 'Brueche', '--lesson-id', 'null', '--observation', 'Ein <em>Viertel</em> bleibt hier Text.', '--question', 'Wie viele Viertel ergeben ein Ganzes?', '--source-kind', 'USER_NOTE', '--source-ref', 'null', '--recorded-at', '2026-10-02T10:00:00Z')
& ./werkzeug/learning-packet.ps1 @packetArguments
```

The wrapper invokes the local Node CLI with an argument array and propagates
its exit code. There is no expression evaluation or content-to-command step.
Windows PowerShell 5.1 users can invoke the Node CLI directly from CMD or use
PowerShell 7.3+. Quote values for the shell in use before they reach the CLI.

## Review and Verification

The browser flow is explicit file selection, a tab-local preview and a continue
button. There is no autonomous background server, shell listener, automatic import, discovery scan,
upload, push, remote write, process interception or propagation. Packet content
does not request these capabilities. Public contributions remain reviewed PRs.

Run the focused suite with:

```bat
node --test werkzeug/test-learning-packets.cjs
```

The tests cover bounds, exact field closure, dates, URLs, lesson membership,
literal markup, immutable inputs, browser/AMD exports, denied browser effects,
CLI flags, bounded UTF-8 file reads and the wrapper's fixed invocation form.
They also check every ID in the actual `curriculum.js` against the Unicode
schema pattern, `knownIds`, exact roundtrip and percent-encoded lesson links.
When `pwsh` 7.3+ is available, the suite also exercises real argument forwarding
and exit codes; otherwise that optional platform test is explicitly skipped.
They use only local synthetic notes and a temporary test directory. These
checks validate this interchange implementation; browser import UI, catalogue
generation, build inclusion and published availability are integration checks
owned by the main application work.
