# Gemeinsam Wissen verbessern

Fehler, Verständnisfragen und Ideen können über Issues oder Discussions besprochen werden. Beschreibe bei einem Fehler die Seite, die Schritte, das erwartete Verhalten und das tatsächlich beobachtete Ergebnis. Entferne persönliche Daten aus Bildern und Beispielen.

Lerninhalte bleiben kostenlos zugänglich. Beiträge sollen freundlich, verständlich, überprüfbar und mit passenden Nutzungsrechten versehen sein. Keine Werbung, persönlichen Angriffe, privaten Schlüssel oder fremden persönlichen Daten veröffentlichen. Moderation erfolgt durch die Repository-Verantwortlichen; es gibt keine Zusage sofortiger Antworten.

Änderungen werden als Pull Request vorgeschlagen. Vorher `npm test` und `npm run build` ausführen. Mengenangaben aus `curriculum.js` ableiten. Wallet-Verbindung, Identitätsprüfung, Lernnachweis und Auszahlung sind getrennte Funktionen; neue finanzielle Wirkungen brauchen einen eigenen geprüften Entwurf.

Für vertrauliche Sicherheitsmeldungen den Kontakt aus dem Impressum verwenden. Eine Veröffentlichung oder Plattform-Mitgliedschaft erteilt keine Erlaubnis für Tests fremder Systeme, Datenzugriffe oder Transaktionen.
