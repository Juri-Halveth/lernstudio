# Lernstudio · interactive learning and personal learning paths

**Concise project guide · EN / RU**

A free learning platform with interactive lessons, a dedicated AI learning path, exercises and customizable animal avatars. Published lessons are directly available without a required account, purchase or subscription. Existing accounts remain optional; without one, progress stays in the browser.

[**Open Lernstudio directly**](https://juri-halveth.github.io/lernstudio/) · [Original technical documentation](README.md) · [Source code](https://github.com/Juri-Halveth/lernstudio/tree/main)

The repository connects the website, deployment tools, content contracts and technical checks. Historical ISC permissions and new protected HALVETH contributions have different recorded terms. Project work documentation remains distinct from institutional qualifications.

This manually edited guide summarizes the audited source. The original technical documentation remains the reference for commands, build requirements, exact versions and detailed evidence.
