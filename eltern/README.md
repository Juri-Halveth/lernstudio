# Компьютер — без паники

[Открыть занятия](https://juri-halveth.github.io/lernstudio/eltern/)

Русский учебный вход для родителей и старших. Начать можно без регистрации: один понятный шаг, крупные кнопки, возможность попробовать ещё раз. Немецкие слова Windows объясняются по-русски. Учебные окна, поиск, вкладки, видео, объявления, файлы и сообщения моделируются внутри страницы; отправки в настоящие сервисы нет.

Прогресс хранится в `localStorage` этого браузера. Другие устройства получают его через добровольный экспорт и импорт JSON-файла в разделе помощи. При запрете хранения упражнения работают в памяти открытой страницы. При импорте сначала показывается результат чтения, затем пользователь отдельно добавляет прогресс. Существующие завершённые занятия сохраняются; неизвестные ID показываются явно. Файл содержит учебные ID и настройки чтения, а не написанные сообщения.

## Где что находится

- `lessons.js`: учебный каталог, объяснения, задания и ссылки на актуальную официальную справку. Новые занятия добавляются сюда; число занятий и шагов интерфейс вычисляет из каталога.
- `progress.js`: проверка формата, объединение завершений и выбор продолжения.
- `app.js`: русская поверхность, учебные взаимодействия, сохранение и перенос.
- `style.css`: крупная типографика, светлый и тёмный фон, узкий экран, клавиатурный фокус и уменьшение движения.
- `../tests/elternmodus.test.cjs`: проверки реальных учебных маршрутов, повторного входа, ошибок хранения, импорта, каталога и отсутствия сетевой отправки.
- `../werkzeug/public-files.js`: точный список публичных файлов.
- `../werkzeug/write-pages-receipt.js`: Pages записывает фактический commit и хеши опубликованных файлов в `build-info.json`.

```bash
npm test
npm run build
node werkzeug/agent-space.mjs verify
node werkzeug/serve.js
```

Учебные ситуации упрощены. Реальные сайты и правила меняются; помощь в учебнике ведёт к источникам, а не фиксирует обещание неизменного интерфейса. Проверки кода показывают работу описанных маршрутов; удобство для конкретного человека проверяется при его использовании.
