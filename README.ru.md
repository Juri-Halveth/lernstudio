# Lernstudio — Wissen gehört allen

**Краткий путеводитель по проекту · EN / RU**

Бесплатная образовательная платформа с интерактивными уроками, отдельным учебным маршрутом по ИИ, упражнениями и настраиваемыми аватарами животных. Опубликованные учебные материалы доступны без обязательной учётной записи, покупки или подписки. Существующие аккаунты необязательны; без аккаунта прогресс хранится в браузере.

Репозиторий связывает сайт, инструменты публикации, контракты содержимого и технические проверки. Исторические разрешения ISC и новые защищённые материалы HALVETH имеют разные документированные условия. Документация работ по проекту отличается от институциональных квалификаций.

Этот путеводитель составлен и отредактирован вручную по проверенному источнику. Исходная техническая документация остаётся справочным материалом для команд, требований сборки, точных версий и подробных проверок.
